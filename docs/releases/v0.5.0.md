# FreeScore for Mac 0.5.0

첫 공개 버전입니다. MIDI 기반 악보 편집기를 **FreeScore for Mac**이라는 이름으로 선보입니다. Made with Codex — 필요한 프로그램을 직접 구현해 쓰는 새로운 시대를 기념합니다.

## 주요 기능

- 오선 악보와 피아노 롤에서 음표 편집, 정렬, 선택, 복사 및 붙여넣기
- 최대 4절 가사, 마디별 코드 입력과 조성 변경에 따른 이조
- 재생선, 녹음, 메트로놈, 반복 및 이동 기호 재생
- 페이지 레이아웃 조정, 세로·가로 인쇄 미리보기와 PDF 인쇄
- `Scripts/midiscore` CLI를 통한 Codex 자동 편집

## 설치

`FreeScore-for-Mac.zip`을 다운로드하여 압축을 풀고 `FreeScore for Mac.app`을 응용 프로그램 폴더로 옮기세요. macOS 14 이상, Apple Silicon 및 Intel Mac을 지원합니다. 현재 자동 배포본은 Apple 서명·공증이 없습니다. 처음 실행할 때 macOS가 차단하면 Finder에서 앱을 Control-클릭해 **열기**를 선택하세요.

`SHA256SUMS.txt`는 ZIP 무결성 확인용입니다. 자세한 기능과 화면은 [공식 소개 페이지](https://evans-kim.github.io/FreeScore-for-Mac/)에 있습니다.
